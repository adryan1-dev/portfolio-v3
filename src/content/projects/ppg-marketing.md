case:
  lede: Uma presença digital construída para explicar o serviço em cinco segundos e conduzir a conversa ao WhatsApp.
  context: Agência de social media, tráfego pago e branding com uma identidade já presente nas redes.
  objective: Explicar o serviço em poucos segundos e levar o visitante a uma conversa no WhatsApp.
  role: Estratégia de conteúdo, sistema visual e desenvolvimento front-end.
  problem: A empresa precisava transformar uma identidade já presente nas redes em uma página que deixasse claro o que vende, para quem vende e qual é o próximo passo.
  strategy: "A mensagem foi organizada em uma sequência direta: reconhecer o problema, entender os serviços, ver trabalho real, conhecer o processo e iniciar uma conversa."
  direction:
    title: Direção visual
    body: Papel quadriculado, amarelo, tipografia condensada e sombras duras levam para a web a linguagem que a marca já usava nos posts.
    tokens:
      - label: Amarelo
        value: "#F5B400, faixas, barras e botões"
        color: "#F5B400"
      - label: Tinta
        value: "#0B0B0B, texto, traços e sombras"
        color: "#0B0B0B"
      - label: Papel
        value: "#F4F3EF, fundo com grid de 32 px"
        color: "#F4F3EF"
      - label: Display
        value: Anton, caixa alta
      - label: Texto
        value: Archivo
      - label: Sombra
        value: Deslocamento duro de 6 a 8 px, sem desfoque
  implementation:
    body: Vite e TypeScript sustentam a página, o Tailwind CSS organiza o sistema visual e o GSAP concentra a camada de movimento.
    points:
      - Página única com âncoras internas
      - Posts reais da marca usados como prova visual
      - Tailwind CSS 4 com tokens do sistema visual
      - GSAP como única camada de movimento
      - Imagens responsivas geradas com Sharp
  quality:
    title: SEO e qualidade
    body: A estratégia e o sistema visual ficaram documentados no repositório para orientar a versão final do site.
    points:
      - Metadados de compartilhamento e dados estruturados
      - Imagens responsivas
      - Publicação pelo GitHub Pages
  limitations:
    - Apresentado como protótipo publicado. Não há métricas comerciais publicadas.
    - Página única, sem CMS nem backend. O conteúdo é atualizado no código.
